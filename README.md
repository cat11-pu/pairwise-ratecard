# ratecard

只依赖 Python 标准库的阶梯计费内核：把一次用量按阶梯区间切成若干段，逐段按
单价算出金额，再按次序叠加折扣，最后套用最低消费与封顶。金额一律是整数分，
单价是百分之一分的整数，用量与折扣值都由调用方以整数注入，内核不读时钟、
不做 I/O、不起线程、不用随机数，同一串调用永远得到同样的结果。

## 口径

- 阶梯写成 (上限, 单价) 的序列，最后一档的上限是 None；第 n 档覆盖上一档
  上限之后的单位，恰好等于某档上限的用量整份归那一档，各段用量之和等于总用量。
- 每段金额等于该段用量乘该段单价、四舍五入到分（半数进位）；账单小计等于
  各段金额之和。
- 折扣分百分比（万分之几的整数，PERCENT_SCALE 为一整份）与定额（分）两种：
  百分比折扣先按登记顺序依次作用在上一步的余额上，再按登记顺序依次扣减定额
  减免，定额最多把余额扣到 0。
- 折后金额不足最低消费的按最低消费收，超过封顶的按封顶收；最低消费不能高于
  封顶。
- 非法参数（阶梯为空、档位上界不递增、最后一档不开口、负单价、负最低消费、
  封顶小于最低消费、重复折扣名、百分比超过一整份、负用量等）一律报错。

## 目录

- `ratecard/core.py`：阶梯校验、用量切分、逐段计价、折扣叠加、最低消费与封顶。
- `tests/test_core.py`：验收用例。

## 运行测试

在项目根目录执行：

```
python3 -m unittest discover -s tests -v
```

Windows 上如果没有 `python3`，可用：

```
python -m unittest discover -s tests -v
```
